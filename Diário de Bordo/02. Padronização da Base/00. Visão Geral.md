
Esta etapa do projeto tem como objetivo construir uma base de dados consolidada a partir das taxas de rendimento escolar e dos microdados do Censo Escolar, abrangendo o período de 2011 a 2025.

O processo está organizado em quatro etapas: (descrever as etapas)

## Pipeline de construção da base

| Etapa                                             | Descrição                                                                                      | Responsável | Status     |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------- | ---------- |
| 01. Revisão e limpeza da base consolidada do INEP | Revisão da base feita pelo Pedro Paulo                                                         | Yasmin      | ✅ Feito    |
| 2. Harmonização dos microdados                    | Equivalência histórica das variáveis e filtragem dos microdados (Código 1)                     | Dani        | ⏳ Pendente |
